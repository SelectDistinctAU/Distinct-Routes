# Press & Media Kit — Distinct Routes

Welcome content creators, bike bloggers, tech journalists, and accessibility advocates! This kit provides everything you need to cover **Distinct Routes**.

---

## 📌 Fast Facts

- **App Name:** Distinct Routes
- **Mission:** Route cyclists, cargo bikes, wheelchairs, and mobility devices away from dangerous traffic arterials onto quiet backstreets and cycleways.
- **Developer:** Select Distinct (Open-Source Project)
- **License:** GNU General Public License v3.0 (GPLv3) — 100% Free & Open Source
- **Platform:** Native Android (Kotlin, Jetpack Compose, Material 3, Target SDK 36)
- **Routing Engine:** Powered by **BBBike.org**
- **Privacy:** 100% On-Device Data Storage — Zero location telemetry, zero ads, zero user accounts.
- **GitHub Repository:** [https://github.com/SelectDistinctAU/Distinct_Routes](https://github.com/SelectDistinctAU/Distinct_Routes)

---

## 🎙️ Core Message & Quote Sheet

> *"Most navigation apps route bikes onto busy highways because they are the shortest distance. Distinct Routes prioritises rider safety above all else — calculating paths through quiet residential backstreets, greenways, and cycle paths where riders actually feel safe."*  
> — **Gerard Bendotti, Project Owner**

---

## 🎯 Key Differentiators to Highlight

1. **Safety-First Pathfinding:** Avoids multi-lane highways and high-speed arterials using BBBike's native `pref_cat=N1` side-street weighting.
2. **Mobility & Accessibility Intelligence:** Tailored speed, slope, and surface rules for **Wheelchairs, Handbikes, Mobility Scooters, Cargo Bikes**, and **Dog Trailers**.
3. **Full-Screen Canvas & Map Long-Press:** Plan routes visually by long-pressing anywhere on the map or using clean 3-D Alliteration inputs (**Departure, Detour, Destination**).
4. **Zero-Tracking Privacy:** 100% local SQLite storage for Favourites and Ride Journal; no registration required.
